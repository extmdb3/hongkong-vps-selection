## 香港VPS不稳定，八成是这三个原因

答案很直接：线路绕路、晚高峰入口拥堵、商家侧的限速和超售。三个原因经常同时出现，而宣传页只会告诉你第一个。

香港到大陆的物理延迟本来就在 30ms 上下，真正的差距出在“回程怎么走”。普通线路晚高峰要从香港绕到别处再回来，延迟翻倍、丢包上升，你看到的“香港 VPS 卡”多半是这么来的。业内常提的三条优化线路，说的是：电信 CN2（AS4809，比普通 163 骨干拥塞更低）、联通 AS9929（国际方向质量较好）、移动 CMIN2（较新的国际网络）。三条都走的商家，会在商品页写“三网优化”或类似说法。

第二个原因是省际入口。同一个商家、同一台机器，上海联通和湖南联通的晚高峰表现可能差一倍，问题不在机房，在你所在省份到出口的那一段。

第三个原因通常没人写进落地页：流量跑完以后怎么办。有的商家直接停机、有的限速到几十 KB/s、有的按 GB 加钱。这一条对“稳定”的影响，往往比 CPU 型号大得多。

## 几个只写在条款里、会咬人的限制

流量用尽是限速，不是断网。达到月流量上限后，带宽被限制到 20 KB/s，服务器保持在线直到下个计费周期。20 KB/s 意味着网页基本打不开，但 SSH 进去备份数据、迁移站点还来得及——这个设计比直接停机温和，比按 GB 扣费厚道。

流量只算出方向。各系列标的是 outbound 流量，入方向不计费。对下载站、素材分发、备份回源这类业务，实际可用量比标称的双向计费方案大不少；反过来，如果你主要做上传型业务，这个优势就用不上。

备份是自动的，但别当灾备。每日自动备份到 AWS S3，出问题能回滚，但它是同商家体系内的备份，不能替代你自己异地留一份。

## 常见问题

**香港VPS哪个稳定，有没有一句话答案？**

电信用户选走 CN2 回程的，移动用户选走 CMIN2 的，联通用户先测本省路由再决定。三家都走的商家（如 GoMami 的香港系列）能覆盖大部分情况，但联通仍需单独验证。

**便宜和稳定的香港VPS能兼得吗？**

能兼得一部分。低价香港机的常见代价是带宽小（三五兆很常见）、晚高峰绕路、流量跑完直接停机或按 GB 加钱。真正贵的是精品回程和带宽，这部分省不掉。

**怎么判断晚高峰会不会掉速？**

看商家是否公开测速入口、是否有第三方在不同时段测过的数据。自己验证的办法是开着监控在 20:00–23:00 跑几轮测速，白天数据不作数。

各家不同。GoMami 的做法是限速至 20 KB/s 并保持在线到下个计费周期，不额外扣费也不停机。买之前一定要在条款或 FAQ 里找到这一条。

**可以装 Windows 吗？**
